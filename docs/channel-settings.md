# 模型与语音账号设置

账号卡片在前端维护草稿，新增、导入、编辑、删除、流式模式和当前账号选择均在点击“保存设置”后生效。关闭设置而未保存会丢弃本次草稿。连接检测与复制操作立即执行，不保存配置；检测语音服务不启动麦克风。

## 本地存储与兼容

`settings.json` 增加 `chatChannels`、`speechChannels`、`activeChatChannelId` 和 `activeSpeechChannelId`。两个池分别保存账号 ID、名称、服务配置、创建时间和最近一次检测结果。检测结果是历史记录，不能保证服务此刻可用；修改连接配置后清除旧检测状态。

保存时，Repository 按激活 ID 解析实际端点并更新兼容字段 `chat` 与 `speech`。问答、纪要、页面理解和转写继续读取这两个端点。内置语音使用保留 ID `local_sherpa` 与 `local_whisper`，不混入云端账号池；Whisper 模型、路径和线程数沿用顶层设置。

旧版单端点配置在加载时转为内存中的账号卡片，密钥和当前服务保留；点击保存后写入新格式。无密钥的默认云端配置不生成已配置卡片。旧前端 `localStorage` 中的账号池转入草稿，当前生效服务仍以后端为准；只有成功保存后才清理旧缓存。删除最后一个账号后，有效端点清空，不继续调用被删除的服务。

完整 API Key 仍按原项目约定保存在本机 JSON 文件中；本次没有新增加密或云端同步。普通设置响应清空所有账号及兼容端点的密钥，返回 `hasKey` 和账号的 `maskedApiKey` 展示预览：超过 8 字符时保留前后各 4 字符，中间为 `*****`；较短密钥完全遮盖。预览不用于鉴权，也不写入设置或备份。前端卡片和编辑框默认显示脱敏值；用户点击复制或编辑框眼睛时才通过专用调用取回指定账号的密钥。再次点击眼睛恢复脱敏，单纯查看不改写密钥。日志与诊断不记录密钥。

## Wails 绑定

调用前缀为 `cue-go-remix/internal/controller.App.`。

| 方法 | 参数 | 行为与返回 |
| --- | --- | --- |
| `GetSettings` | 无 | 返回包含两个账号池的脱敏设置。 |
| `SaveSettings` | 完整设置草稿 | 校验账号、合并密钥、解析当前选择并原子保存；成功返回脱敏设置，失败保留原设置。录音中拒绝改变实际语音端点、采集或模型参数。 |
| `TestChannelEndpoint` | `kind: chat/speech`、扁平账号对象（含 `id` 与端点字段） | 使用账号草稿检测；仅按同类型、ID、服务商和地址继承留空密钥。新账号可显式传入草稿密钥。返回 `success`、`latency`（毫秒）及 `message`。 |
| `GetChannelKey` | `kind: chat/speech`、已保存账号 ID | 用于用户点击复制或显示完整密钥；返回该账号密钥，未知账号或空密钥返回错误。调用与返回值不得写日志。 |
| `TestEndpoint` | `kind`、单端点 | 保留旧单端点检测接口；新卡片使用 `TestChannelEndpoint`，避免检测非当前账号时借用当前账号密钥。 |

密钥留空只在原账号的服务商、地址均未变化时继承。更换地址、新账号、其他类别账号不会借用旧凭据。`clearKey: true` 显式删除密钥；保存失败时不会修改当前已生效配置。

官方登录、OAuth 和 Token/JSON 标签仍是禁用占位；当前支持 API Key 配置，以及 JSON/逐行文本导入现有协议账号。

## 聊天接口协议

兼容接口渠道可在编辑窗口选择 `Chat Completions` 或 `Responses`，对应配置字段 `chatProtocol` 的值分别为 `chat-completions` 和 `responses`。旧配置省略该字段时沿用原有接口；Anthropic 与 Gemini 继续使用各自原生协议，语音渠道不使用此字段。

Responses 使用 `/responses` 路径、`instructions` 和 `input` 请求结构，支持文本及 base64 截图、普通 JSON 和 SSE 流式回答。请求显式设置 `store: false`，不创建远端会话；这不代表网关本身承诺零留存。流式仅展示回答正文，完成快照不会重复追加，失败、提前断流或未完成终态会报告错误。完整接口地址不会重复拼接；误将另一种完整接口填为 Base URL 时明确报错。

协议修改先进入草稿，点击“保存设置”后生效。连接检测立即使用草稿所选协议及流式模式，但不保存设置。切换协议而不更换账号、提供商和地址时保留已有密钥；JSON 导入也支持 `chatProtocol` 字段。

聊天连接检测总时限为 60 秒，语音检测沿用 10 秒。Responses 流式请求在首个响应前最多等待 60 秒，开始接收后保留连续 25 秒无数据的中断保护。

网关明确表示只支持 Responses 时，错误提示引导修改协议，不自动重试其他接口。日志仅增加固定 `protocol` 和 `category` 标识，同时保留 HTTP 状态分类，禁止记录地址、密钥或请求及响应正文。

## 验证

后端回归位于 `internal/repository/channels_test.go` 与 `internal/service/channels_test.go`，覆盖迁移重开、同域账号密钥隔离、非当前账号检测、真实问答选用、录音期间切换保护、清除与改地址、删除最后账号、脱敏深拷贝和写盘失败。

界面验收使用隔离的模拟桌面服务检查草稿、取消、统一保存、编辑回填、导入校验、连接检测、密钥复制、搜索焦点及子弹窗点击区域。测试不使用真实服务凭据或录音设备；实际服务商的可用性需由卡片中的检测按钮确认。
